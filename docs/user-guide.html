User Guide

Play anything on your Mac

Uncork brings your PC game stores and games to your Apple Silicon Mac, in one friendly place. No Windows, no tinkering, no command line. This guide walks you through it.

Welcome

Uncork installs and runs Windows game launchers and games on your Mac for you. It gives every store, Steam, Epic, GOG and more, one home where you install, launch, and play. Where a store or game has a real Mac version, Uncork uses that; where it does not, Uncork runs the Windows version behind the scenes.

⚑

Good to know. Not every Windows game runs on a Mac yet. Uncork marks each game with how well it is expected to work, so you always know what to expect before you install.

First run

The first time you open Uncork it runs a short setup that gets your Mac ready. You do not need an admin password or any developer tools. Some pieces (the graphics engine, and the Steam client if you use Steam) are downloaded the first time you need them, so the app itself stays small and the download happens once.

  • Let the setup finish. It only runs once.
  • When it is done, you land on the Stores page.

Add a store

Open Stores and pick a storefront to set up. Uncork does the whole install for you and shows progress the whole way.

The one-click stores

  • Steam, Epic, GOG: click to set up, then sign in with your own account. Your owned games appear in your Library.
  • Battle.net and itch.io: these install as their real Mac apps, so they run directly with nothing extra.

Add your own store

Use Add Store for anything not listed. Choose Windows (Uncork installs it and you point it at the launcher) or Mac (pick an app you already have). You can also share a setup: once a store works well, use Save as Template to export it, and others can Run Template to get the exact same setup.

⚑

Each store tile shows a macOS or Windows badge so you can see at a glance how it runs.

Browse the store

Once a store is set up, it gets its own entry under Browse in the sidebar (Steam, Epic and GOG all have one). That opens the store's web page right inside Uncork, so you can buy or claim games without leaving the app. After you buy or claim something, open your Library and refresh to install it. If you add your own store, you can give it a store page too.

Where games download

For Epic and GOG you can pick where games install (handy if your Mac's main drive is short on space). Open the store's ⋯ menu on the Stores page and choose Install location…, then pick a folder. Games already installed move to the new place, and everything you install later goes there too. Steam manages its own download folders in the Steam client.

Play from your library

The Library shows every game you own across your stores in one grid. Use the Mac | Windows | All tabs to filter, and the search box to find a title fast. Each tile shows a small badge for whether it is a Mac or Windows game.

  • Click a game to open its page.
  • Press Install if it is not downloaded yet, then Play.
  • While a game is running, its tile shows a Running marker; press Quit on its page to stop it.
⚑

Installed at a glance. A downloaded game shows in full colour with a small green check. One you own but have not downloaded is dimmed with a Not installed badge (and a progress bar while it downloads).

Organize your library

Right-click any game (or use its tile menu) to tidy a big library:

  • Add to Favorites: marks the game with a star. Turn on Favorites only in the filter menu to see just those.
  • Hide game: tucks away games you will not play. They disappear from the grid until you turn on Show hidden in the filter menu, where you can unhide them.
  • Collections: group games however you like (for example "Co-op" or "Finished"). Create a collection from the same menu, then filter to one with the Collection picker. A collection disappears on its own once it has no games left.

Add your own games

Have a game that did not come from a store? On the Library page use the + menu:

  • Add Windows Game: pick a Windows .exe. Uncork runs it for you, and can give it its own isolated space so its setup stays separate from other games (recommended).
  • Add Mac Game: pick a native .app. It runs directly.

Set artwork

Most games get their cover and banner art automatically. For anything that does not, or if you just want a different image, open the game's page and use the photo button on the banner:

  • Set banner image: the wide image across the top of the game page. A wide image looks best.
  • Set cover image: the picture on the Library tile.
  • Reset to default art: go back to the automatic art.

Your image is copied into Uncork, so it stays even if you move or rename the original file.

Make a game run better

If a game will not start or misbehaves, open its page. Everything you need is there:

  • Compatibility profile: the engine the game runs on. If a game will not start, try a different profile (you may be offered one to download).
  • Windows version: switch this if a game says your Windows is unsupported.
  • Performance overlay: shows FPS and GPU stats on screen while you play.
  • Apply fixes: re-runs every known fix for the game. Use it when a game will not launch.
  • View launch log: shows what happened the last time you pressed Play, the steps Uncork took and the game's own output. Open this first when a game will not start; you can copy it to share when asking for help.
  • Relaunch with diagnostics: if the normal log does not show why a game fails, use this to start it again with extra logging turned on, then open the log for more detail.
  • Verify & repair (Epic and GOG): re-checks the game's files and re-downloads anything missing or damaged. Use it if a game crashes or won't start after an interrupted download.
⚑

Anti-cheat games. Some online games (for example ones using Easy Anti-Cheat or BattlEye) simply cannot run on Apple Silicon, the anti-cheat has no Mac version. When that is the case, the game's page shows a clear red notice, so you know it is a hard limit and not something a setting can fix.

⚑

The badge on each game page tells you if it should work, needs work, or is untested, so you know whether a game is worth troubleshooting.

Cloud saves

Keep your progress in sync across machines. Open a game's page and find the Cloud saves card:

  • Epic: press Sync now. Uncork usually finds the save location for you.
  • GOG: first choose the folder where the game keeps its saves (the card has a picker), then Sync now.
  • Need to force a direction? The ⋯ menu on the card has Upload to cloud and Download from cloud.
⚑

Steam saves sync on their own through Steam Cloud in the Steam client, so there is nothing to do for Steam games. Syncing is manual for now: run it before you switch machines and after you finish playing.

Controllers

Uncork turns on gamepad support automatically for every game. What matters is whether your Mac itself recognizes the controller, since Uncork can only pass on a pad macOS already sees.

  • These work: a genuine Xbox Series or Xbox One controller (wired or Bluetooth), a PlayStation DualSense or DualShock 4, any MFi controller, and 8BitDo pads in their Xinput mode.
  • These do not: third-party Xbox controllers that only Windows supports (for example the Turtle Beach Recon). macOS has no driver for them, so no app can use them. A hardware adapter (such as a MayFlash Magic-NS or an 8BitDo wireless adapter) can convert one into a controller your Mac accepts.
  • Not detected? Start the game first, then unplug and replug the controller. macOS sometimes misses one that was connected before launch.

Try another Wine version

Uncork runs Windows games with an engine called Wine. Most games are happy on the default, but occasionally a specific version works better. Open Wine Downloader to download and keep several versions, including older ones, so you can roll a game back to a version that worked.

Remove a store or game

  • A store: on the Stores page, open a store's ⋯ menu (or right-click it) and choose Remove store.
  • A downloaded game: open its page and use Uninstall (Epic/GOG) to delete the game files. You can reinstall anytime.
  • A game you added yourself: open its page and choose Remove from Library. This only removes it from Uncork; the files on disk are left alone.

Quitting Uncork

When you quit, Uncork cleanly closes the background Steam client (if it was running) and shows a small "Closing" note while it finishes. That is normal and takes a moment. If a game is still running, quit the game first.

If something goes wrong

  • A game will not start: open its page, check View launch log to see why, try Apply fixes, then a different Compatibility profile.
  • A store will not finish installing: some Windows-only launchers cannot run on a Mac yet. If a native Mac version exists (for example Battle.net), use that instead.
  • Still stuck: Uncork is open source, and the Developer Guide in the sidebar explains how it all works.
